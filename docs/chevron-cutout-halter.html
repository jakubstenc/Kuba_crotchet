Gauge-Parameterized 100% Cotton Halter with 90° Inverted-V Sternum Cutout & Corset Ribbed Band

Published

Project Overview

This reproducible pattern generates a Women’s Size S/M 100% Cotton Mitered Chevron Halter Top calibrated for an ~88 cm bust / ~76 cm underbust (38.0 cm front panel baseline + 2 × 14.0 cm ribbed back extensions + 10.0 cm corset lace-up gap).

Unlike naive chevron patterns that assume square stitches, every stitch count, short-row turn, blueprint polygon, and yardage estimate on this page is computed dynamically in R from Euclidean trigonometry using the true aspect ratio of half double crochet (sts/cm != rows/cm). Edit any gauge or measurement variable in the setup chunk below and re-render with Quarto to recalibrate the entire pattern.

Exact Mitered Trigonometric Engine

Because hdc stitches are narrower than they are tall (1 / sts_per_cm = 0.455 cm wide vs. dT = 1 / rows_per_cm = 0.625 cm perpendicular row thickness), naive +1 or +2 increases every row distort the 90° chevron angle:

  • Perpendicular row thickness: \(dT = 1 / \text{rows\_per\_cm}\). Along a \(45^\circ\) chevron leg, advancing perpendicular to the leg by \(dT\) shifts the vertical spine peak upward by \(\Delta y_{\text{spine}} = dT\sqrt{2}\) and shifts a horizontal \(180^\circ\) rib baseline outward by \(\Delta x_{\text{rib}} = dT\sqrt{2}\).
  • 90° Center Peak & 180° Rib Baseline Rate: Projecting the new vertex back onto the previous \(45^\circ\) leg yields an exact leg extension of \(dT / \tan(45^\circ) = dT\) cm per row at the spine (and likewise \(+dT\) cm per row at the flat horizontal rib edge), requiring: \[r_{\text{miter}} = dT \times \text{sts\_per\_cm} = \frac{\text{sts\_per\_cm}}{\text{rows\_per\_cm}} = 1.375 \text{ sts/row/wing}\] Our engine tracks exact cumulative Euclidean arc length with staggered tie-breaking between +1 ((1 hdc, ch 1, 1 hdc)) and +2 ((2 hdc, ch 1, 2 hdc)) so stitch counts never drift by more than 0.5 stitches (~2 mm) on any row.
  • Armhole Side-Bust Pivot Condition: Decreasing k stitches at the row end shortens the leg by \(s = k / \text{sts\_per\_cm}\), shifting the outer coordinate by \(\Delta x = (dT - s)/\sqrt{2}\) and \(\Delta y = (dT + s)/\sqrt{2}\). A single hdc2tog (k = 1, \(s = 0.455\text{ cm} < dT = 0.625\text{ cm}\)) actually drifts outward (\(\Delta x = +0.12\text{ cm/row}\)). To pivot strictly upward and inward (\(\Delta x < 0\)), the engine computes \(k_{\text{dec}} = \lfloor r_{\text{miter}} \rfloor + 1 = 2\) ([hdc2tog] 2x at outer edges, giving \(\Delta x = -0.20\text{ cm/row}, \Delta y = +1.08\text{ cm/row}\)).

build_chevron_halter <- function(
  sts_per_cm, rows_per_cm, band_sts_per_cm, band_rows_per_cm,
  front_width_cm, cutout_height_cm, body_height_cm, neck_flat_width_cm,
  band_height_cm, band_total_length_cm, icord_length_cm,
  palette_df, stripe_cycle_codes, rows_per_stripe = 2L
) {
  # Fundamental differential geometry constants
  dT         <- 1 / rows_per_cm
  ds         <- 1 / sts_per_cm
  step_c     <- dT * sqrt(2)            # Intercept advance along x + y = c per hdc row
  rate_miter <- dT * sts_per_cm         # Exact sts/row/wing for 90-deg miter & 180-deg base

  # Cutout & Phase 1 foundation geometry
  cutout_base_cm <- 2 * cutout_height_cm
  cutout_leg_cm  <- cutout_height_cm * sqrt(2)
  leg0_sts       <- as.integer(round(cutout_leg_cm * sts_per_cm))
  fsc_total_sts  <- 2L * leg0_sts + 1L  # Odd count: leg + 1 marked center st + leg

  # Row milestones across phases
  rib_wing_target_cm <- (front_width_cm - cutout_base_cm) / 2
  n_rib_rows  <- as.integer(round(rib_wing_target_cm / step_c))
  n_peak_rows <- as.integer(round((body_height_cm - cutout_height_cm) / step_c))
  n_neck_rows <- as.integer(round((neck_flat_width_cm / 2) / step_c))
  n_hdc_rows  <- n_peak_rows + n_neck_rows

  # Minimum outer-edge decrease so dx = (dT - k*ds)/sqrt(2) < 0 (strictly inward taper)
  dec_outer_sts <- as.integer(floor(rate_miter) + 1L)

  color_lookup <- setNames(
    paste0(palette_df$code, " (", palette_df$name, ")"),
    palette_df$code
  )
  hex_lookup <- setNames(palette_df$hex, palette_df$code)

  # Initialize state trackers
  rows_list      <- list()
  poly_list      <- list()
  wing_sts       <- leg0_sts
  cum_peak_exact <- 0.0; cum_peak_int <- 0L
  cum_rib_exact  <- 0.0; cum_rib_int  <- 0L
  cum_neck_exact <- 0.0; cum_neck_int <- 0L

  # Row 0: Phase 1 Foundation Arch (fsc framing cutout in C2 so first stripe begins cleanly)
  first_code <- stripe_cycle_codes[1]
  rows_list[[1]] <- tibble::tibble(
    Row              = "Row 0 (Fdn)",
    row_num          = 0L,
    Phase            = "Phase 1: Foundation Arch",
    color_code       = first_code,
    Color            = color_lookup[[first_code]],
    Row_Start_Action = paste0("fsc ", leg0_sts, " (right leg)"),
    Center_Action    = "1 fsc (mark center spine st)",
    Row_End_Action   = paste0("fsc ", leg0_sts, " (left leg)"),
    Wing_Sts         = leg0_sts,
    Total_Sts        = fsc_total_sts,
    Active_HDC_Equiv = fsc_total_sts
  )

  # Physical coordinate state for right-half polygons (mirrored to left half x -> -x)
  y_collar_actual <- cutout_height_cm + n_peak_rows * step_c
  x_out_bot       <- cutout_height_cm
  y_out_bot       <- 0.0

  for (r in seq_len(n_hdc_rows)) {
    c_code <- stripe_cycle_codes[((r - 1L) %/% rows_per_stripe) %% length(stripe_cycle_codes) + 1L]
    c_bot  <- cutout_height_cm + (r - 1L) * step_c
    c_top  <- cutout_height_cm + r * step_c

    if (r <= n_rib_rows) {
      phase_label <- "Phase 2: Rib Baseline"
      # Staggered rounding tie-breakers keep wing_sts within <= 0.5 st of exact Euclidean length
      cum_peak_exact <- cum_peak_exact + rate_miter
      inc_peak       <- as.integer(floor(cum_peak_exact + 0.5)) - cum_peak_int
      cum_peak_int   <- cum_peak_int + inc_peak

      cum_rib_exact  <- cum_rib_exact + rate_miter
      inc_rib        <- as.integer(ceiling(cum_rib_exact - 0.5)) - cum_rib_int
      cum_rib_int    <- cum_rib_int + inc_rib

      wing_sts  <- wing_sts + inc_rib + inc_peak
      total_sts <- 2L * wing_sts + 1L

      start_act <- sprintf("+%d st (%d hdc in 1st st)", inc_rib, inc_rib + 1L)
      peak_act  <- sprintf("(%d hdc, ch 1, %d hdc) [+%d/wing]", inc_peak, inc_peak, inc_peak)
      end_act   <- sprintf("+%d st (%d hdc in last st)", inc_rib, inc_rib + 1L)

      x_in_bot <- 0.0;   y_in_bot <- c_bot
      x_in_top <- 0.0;   y_in_top <- c_top
      x_out_top <- c_top; y_out_top <- 0.0

    } else if (r <= n_peak_rows) {
      phase_label <- "Phase 3: Armhole Taper"
      cum_peak_exact <- cum_peak_exact + rate_miter
      inc_peak       <- as.integer(floor(cum_peak_exact + 0.5)) - cum_peak_int
      cum_peak_int   <- cum_peak_int + inc_peak

      wing_sts  <- wing_sts - dec_outer_sts + inc_peak
      total_sts <- 2L * wing_sts + 1L

      start_act <- sprintf("-%d sts ([hdc2tog] x%d)", dec_outer_sts, dec_outer_sts)
      peak_act  <- sprintf("(%d hdc, ch 1, %d hdc) [+%d/wing]", inc_peak, inc_peak, inc_peak)
      end_act   <- sprintf("-%d sts ([hdc2tog] x%d)", dec_outer_sts, dec_outer_sts)

      x_in_bot  <- 0.0; y_in_bot <- c_bot
      x_in_top  <- 0.0; y_in_top <- c_top
      x_out_top <- x_out_bot + (dT - dec_outer_sts * ds) / sqrt(2)
      y_out_top <- c_top - x_out_top

    } else {
      phase_label <- "Phase 4: Neck Short Rows"
      sr_idx      <- r - n_peak_rows
      cum_neck_exact <- cum_neck_exact + rate_miter
      dec_neck       <- as.integer(floor(cum_neck_exact + 0.5)) - cum_neck_int
      cum_neck_int   <- cum_neck_int + dec_neck

      wing_sts  <- wing_sts - dec_outer_sts - dec_neck
      total_sts <- 2L * wing_sts  # Worked separately on Left & Right shoulders

      if (sr_idx %% 2L == 1L) {
        # Odd short row: work from outer armhole edge up toward collarbone, stop short
        start_act <- sprintf("Outer: [hdc2tog] x%d (-%d sts)", dec_outer_sts, dec_outer_sts)
        peak_act  <- sprintf("Turn %d st(s) before neck edge", dec_neck)
        end_act   <- "Repeat symm. on 2nd shoulder"
      } else {
        # Even short row: sl st down along flat collar, work down to outer armhole decrease
        start_act <- sprintf("Neck: sl st %d, ch 1 (-%d sts)", dec_neck, dec_neck)
        peak_act  <- "Center unworked (flat collar)"
        end_act   <- sprintf("Outer: [hdc2tog] x%d (-%d sts)", dec_outer_sts, dec_outer_sts)
      }

      x_in_bot  <- c_bot - y_collar_actual; y_in_bot <- y_collar_actual
      x_in_top  <- c_top - y_collar_actual; y_in_top <- y_collar_actual
      x_out_top <- x_out_bot + (dT - dec_outer_sts * ds) / sqrt(2)
      y_out_top <- c_top - x_out_top
    }

    rows_list[[r + 1L]] <- tibble::tibble(
      Row              = paste0("Row ", r),
      row_num          = r,
      Phase            = phase_label,
      color_code       = c_code,
      Color            = color_lookup[[c_code]],
      Row_Start_Action = start_act,
      Center_Action    = peak_act,
      Row_End_Action   = end_act,
      Wing_Sts         = wing_sts,
      Total_Sts        = total_sts,
      Active_HDC_Equiv = total_sts
    )

    # Store right and mirrored left wing polygons for ggplot2 blueprints
    poly_list[[2L * r - 1L]] <- tibble::tibble(
      row_num = r, side = "Right", poly_id = paste0("R_", r),
      Phase = phase_label, color_code = c_code, hex = hex_lookup[[c_code]],
      x = c(x_in_bot, x_out_bot, x_out_top, x_in_top),
      y = c(y_in_bot, y_out_bot, y_out_top, y_in_top)
    )
    poly_list[[2L * r]] <- tibble::tibble(
      row_num = r, side = "Left", poly_id = paste0("L_", r),
      Phase = phase_label, color_code = c_code, hex = hex_lookup[[c_code]],
      x = -c(x_in_bot, x_out_bot, x_out_top, x_in_top),
      y =  c(y_in_bot, y_out_bot, y_out_top, y_in_top)
    )

    x_out_bot <- x_out_top
    y_out_bot <- y_out_top
  }

  # Final Framing Row: 1 continuous row of C2 (Ochre) sc framing both armholes + neckline
  side_bust_len_cm  <- sqrt((x_out_bot - (cutout_height_cm + n_rib_rows * step_c))^2 + y_out_bot^2)
  diag_arm_len_cm   <- sqrt((x_out_bot - (c_top - y_collar_actual))^2 + (y_collar_actual - y_out_bot)^2)
  collar_actual_cm  <- 2 * (c_top - y_collar_actual)
  armhole_sc_per_sd <- as.integer(round((side_bust_len_cm + diag_arm_len_cm) * sts_per_cm))
  collar_sc_sts     <- as.integer(round(collar_actual_cm * sts_per_cm))
  trim_total_sc     <- 2L * armhole_sc_per_sd + collar_sc_sts

  rows_list[[n_hdc_rows + 2L]] <- tibble::tibble(
    Row              = paste0("Row ", n_hdc_rows + 1L, " (Trim)"),
    row_num          = n_hdc_rows + 1L,
    Phase            = "Phase 4: Collar & Armhole Edging",
    color_code       = "C2",
    Color            = color_lookup[["C2"]],
    Row_Start_Action = paste0("RS join at R underarm: ", armhole_sc_per_sd, " sc up R armhole"),
    Center_Action    = paste0(collar_sc_sts, " sc across flat horizontal neckline"),
    Row_End_Action   = paste0(armhole_sc_per_sd, " sc down L armhole"),
    Wing_Sts         = armhole_sc_per_sd,
    Total_Sts        = trim_total_sc,
    Active_HDC_Equiv = as.integer(round(trim_total_sc * 0.75))
  )

  # Perpendicular sc BLO Ribbed Waistband & Cutout Stabilization Calculations (2.5 mm hook, C1)
  band_width_sts    <- as.integer(round(band_height_cm * band_sts_per_cm))
  back_ext_cm       <- (band_total_length_cm - front_width_cm) / 2
  rows_back_ext     <- 2L * as.integer(round((back_ext_cm * band_rows_per_cm) / 2))
  rows_front_wing   <- 2L * as.integer(round((rib_wing_target_cm * band_rows_per_cm) / 2))
  rows_cutout_brdg  <- 2L * as.integer(round((cutout_base_cm * band_rows_per_cm) / 2))
  band_total_rows   <- 2L * rows_back_ext + 2L * rows_front_wing + rows_cutout_brdg

  cutout_leg_sc     <- as.integer(round(cutout_leg_cm * band_sts_per_cm))
  cutout_base_sc    <- as.integer(round(cutout_base_cm * band_sts_per_cm))
  cutout_round_sts  <- 2L * (cutout_leg_sc - 1L) + 1L + cutout_base_sc # incl. sc3tog apex

  icord_rows_each   <- as.integer(round(icord_length_cm * band_rows_per_cm))

  list(
    rows_df           = bind_rows(rows_list),
    polys_df          = bind_rows(poly_list),
    dT                = dT,
    step_c            = step_c,
    rate_miter        = rate_miter,
    leg0_sts          = leg0_sts,
    fsc_total_sts     = fsc_total_sts,
    n_rib_rows        = n_rib_rows,
    n_peak_rows       = n_peak_rows,
    n_neck_rows       = n_neck_rows,
    n_hdc_rows        = n_hdc_rows,
    dec_outer_sts     = dec_outer_sts,
    front_actual_cm   = 2 * (cutout_height_cm + n_rib_rows * step_c),
    y_collar_actual   = y_collar_actual,
    collar_actual_cm  = collar_actual_cm,
    x_underarm_top    = x_out_bot,
    y_underarm_top    = y_out_bot,
    armhole_sc_per_sd = armhole_sc_per_sd,
    collar_sc_sts     = collar_sc_sts,
    band_width_sts    = band_width_sts,
    back_ext_cm       = back_ext_cm,
    rows_back_ext     = rows_back_ext,
    rows_front_wing   = rows_front_wing,
    rows_cutout_brdg  = rows_cutout_brdg,
    band_total_rows   = band_total_rows,
    cutout_leg_sc     = cutout_leg_sc,
    cutout_base_sc    = cutout_base_sc,
    cutout_round_sts  = cutout_round_sts,
    icord_rows_each   = icord_rows_each
  )
}

pat <- build_chevron_halter(

  Row    = seq_len(tot_grid_rows)
) %>%
  mutate(
    # Physical coordinates (cm) of each discrete stitch tile center
    x_cm    = (Stitch - center_col) / sts_per_cm,
    y_cm    = (Row - n_band_rows - 0.5) / rows_per_cm,
    abs_x   = abs(x_cm),
    c_diag  = abs_x + y_cm,

    # Maximum outer half-width of the front body at height y_cm
    max_x_at_y = case_when(
      y_cm < 0 ~ half_front_cm,
      y_cm <= y_ua_cm ~ half_front_cm + (x_ua_cm - half_front_cm) * (y_cm / max(y_ua_cm, 0.01)),
      y_cm <= y_col_cm ~ x_ua_cm + (half_collar_cm - x_ua_cm) * ((y_cm - y_ua_cm) / max(y_col_cm - y_ua_cm, 0.01)),
      TRUE ~ -1.0
    ),

    # Chevron row index (1..n_hdc_rows) corresponding to 45-deg coordinate c_diag
    chev_row = as.integer(ceiling((c_diag - cutout_height_cm) / pat$step_c)),
    stripe_idx = ((pmax(chev_row, 1L) - 1L) %/% rows_per_stripe) %% length(stripe_cycle_codes) + 1L,
    chev_code  = stripe_cycle_codes[stripe_idx],

    # Structural region classification
    Part = case_when(
      Row <= n_band_rows ~ "Base Band (C1 sc BLO)",
      y_cm > y_col_cm ~ "Empty Space",
      abs_x > max_x_at_y ~ "Empty Space",
      c_diag < cutout_height_cm - 0.35 ~ "Empty Space",
      c_diag < cutout_height_cm + 0.28 ~ "Cutout Lock Border (C1 sc/sl st)",
      y_cm >= y_col_cm - (1 / rows_per_cm) & abs_x <= half_collar_cm + 0.35 ~ "Collar & Armhole Trim (C2 sc)",
      abs_x >= max_x_at_y - 0.48 ~ "Collar & Armhole Trim (C2 sc)",
      TRUE ~ paste0("Chevron Stripe: ", chev_code)
    ),

    # Map every active tile to its exact yarn color label
    Yarn_Shade = case_when(
      Part == "Empty Space" ~ NA_character_,
      Part %in% c("Base Band (C1 sc BLO)", "Cutout Lock Border (C1 sc/sl st)") ~ "C1: Forest Green (Band & Cutout Lock)",
      Part == "Collar & Armhole Trim (C2 sc)" ~ "C2: Ochre / Mustard (Body & Trim)",
      chev_code == "C1" ~ "C1: Forest Green (Band & Cutout Lock)",
      chev_code == "C2" ~ "C2: Ochre / Mustard (Body & Trim)",
      chev_code == "C3" ~ "C3: Cream",
      chev_code == "C4" ~ "C4: Dusty Rose"
    )
  ) %>%
  filter(Part != "Empty Space")

Because chevron rows run along a 45° diagonal, this companion unwrapped geom_tile matrix flattens each pattern row horizontally so 1 tile = 1 exact crochet stitch worked in that row (with special stitch actions highlighted along the outer edges and center spine).

# Build exact stitch-by-stitch tile rows from pat$rows_df
unwrapped_tiles <- lapply(seq_len(nrow(pat$rows_df)), function(i) {
  rw    <- pat$rows_df[i, ]
  r_num <- rw$row_num
  w_sts <- rw$Wing_Sts

  if (rw$Phase == "Phase 4: Neck Short Rows") {
    # Leave visual gap in the center proportional to unworked collar stitches
    sr_step <- r_num - pat$n_peak_rows
    gap_half <- 1L + 2L * sr_step
    left_x   <- seq(-gap_half - w_sts + 1L, -gap_half)
    right_x  <- seq(gap_half, gap_half + w_sts - 1L)
    tibble::tibble(
      Row_Num    = r_num,
      Stitch_Pos = c(left_x, right_x),
      Color_Code = rw$color_code,
      Action     = case_when(
        Stitch_Pos %in% c(min(left_x), min(left_x) + 1L, max(right_x) - 1L, max(right_x)) ~ "Decrease (hdc2tog)",
        TRUE ~ "Standard Stitch"
      )
    )
  } else if (r_num == pat$n_hdc_rows + 1L) {
    # Continuous sc collar & armhole framing row
    half_tot <- rw$Total_Sts %/% 2L
    xs       <- seq(-half_tot, half_tot)
    tibble::tibble(
      Row_Num    = r_num,
      Stitch_Pos = xs,
      Color_Code = rw$color_code,
      Action     = "Standard Stitch"
    )
  } else {
    # Full mitered chevron rows (Phase 1, 2, 3): Left Wing + Center Spine (0) + Right Wing
    left_x  <- seq(-w_sts, -1L)
    right_x <- seq(1L, w_sts)
    xs      <- c(left_x, 0L, right_x)
    tibble::tibble(
      Row_Num    = r_num,
      Stitch_Pos = xs,
      Color_Code = rw$color_code,
      Action     = case_when(
        Stitch_Pos == 0L ~ "Center Spine (ch-1 / fsc)",
        rw$Phase == "Phase 3: Armhole Taper" &
          Stitch_Pos %in% c(min(left_x), min(left_x) + 1L, max(right_x) - 1L, max(right_x)) ~ "Decrease (hdc2tog)",
        rw$Phase == "Phase 2: Rib Baseline" &
          Stitch_Pos %in% c(min(left_x), max(right_x)) ~ "Increase (+1/+2)",
        TRUE ~ "Standard Stitch"
      )
    )
  }
}) %>% bind_rows()

5. Abbreviations & Cotton Structural Notes (US Crochet Terms)

  • Ch — Chain
  • Sl St — Slip stitch
  • SC — Single crochet
  • SC BLO — Single crochet worked in the back loop only (creates elastic vertical knit-look ribbing when turned perpendicular)
  • FSC — Foundation single crochet (creates chain + first sc row simultaneously with matching stretch)
  • HDC — Half double crochet
  • HDC2Tog — Half double crochet 2 stitches together ([hdc2tog] x2 works two consecutive decreases over 4 stitches, decreasing by 2 stitches)
  • SC3Tog — Single crochet 3 stitches together (mitered inner-corner decrease at cutout apex)
  • JAYG — Join-as-you-go slip-stitch attachment

Structural Anti-Sag Engineering for 100% Cotton

  1. Zero-Bulk Stripe Transitions (Crocheting Over Tails): Because every stripe is exactly 2 rows (C2 -> C3 -> C4 -> C1), all color joins up to Row 11 land at the same right-hand edge. Change colors on the final yarn-over pull-through of the second row in each stripe, leave a 10 cm tail, and crochet directly over both the old and new yarn tails for the first 6–8 sts of the next row. In inelastic 100% cotton, locking tails inside the outer edge reinforces the rib baseline and armhole selvedges while eliminating weaving-in bulk.
  2. Preventing Sternum Cutout Bridge Dip: Across the 22.0 cm empty sternum cutout, the Forest Green (C1) ribbed band bridges open air without upper fabric pulling it upward. Switching down to the 2.5 mm hook and working 1 snug round of sc (sc3tog at the apex) + 1 round of surface sl st around the interior perimeter of the cutout triangle locks the 45° bias edges and anchors the bridged band horizontally so it never sags or gapes on the body.
  3. Why Outer Armholes Use [hdc2tog] x2: At 2.2 sts/cm and 1.6 rows/cm, one hdc row is 0.625 cm thick whereas one hdc stitch is only 0.455 cm wide. A single hdc2tog (-1 st) fails to overcome the outward \(45^\circ\) row projection. Working [hdc2tog] x2 (-2 sts at each outer edge) cleanly pivots the side-bust inward toward the collarbone.

7. Step-by-Step Written Instructions

Phase 1 — Foundation Arch (Row 0, 3.0 mm hook)

  1. With C2 (Ochre) and the 3.0 mm hook, work 69 fsc.
  2. Place a locking stitch marker in the 35th (center) stitch (34 sts on Right Wing + 1 center spine st + 34 sts on Left Wing). Turn. (Note: Row 0 establishes the flexible 15.56 cm-per-leg cutout foundation rim; Rows 1–2 begin the 2-row stripe count in C2.)

Phase 2 — Flat Rib Baseline Expansion (Rows 1–9, 3.0 mm hook)

Work back and forth in 2-row stripes following the color rotation C2 -> C3 -> C4 -> C1, changing colors at the right-hand edge after every even-numbered row and crocheting over yarn tails for 6–8 sts:

  • Row 1 (RS, C2): Ch 1 (does not count as a st throughout), follow the Row Start Action in the first fsc (2 hdc for +1 inc, or 3 hdc for +2 inc), hdc in each remaining fsc up to the marked center stitch, work the Center Peak Action — either (1 hdc, ch 1, 1 hdc) or (2 hdc, ch 1, 2 hdc) as listed in the table — directly into the marked center fsc (move marker to the new ch-1 space), hdc down the second wing to the last st, and work the Row End Action in the last st. Turn. (36 sts per wing; 73 sts total incl. ch-1 sp).
  • Rows 2–9: Ch 1, work the listed Row Start Action (2 hdc or 3 hdc in first st), hdc in each st to the center ch-1 space, work the listed Center Peak Action into the ch-1 space, hdc in each st to the last st, and work the listed Row End Action in the final st. Turn.
  • After Row 9 (C2 (Ochre / Mustard)), your flat 180° bottom rib edge measures 37.9 cm (8.0 cm left wing + 22.0 cm almost-underboob center cutout + 8.0 cm right wing) with 58 sts per wing. Place markers at both outer bottom underarm/rib corners.

Phase 3 — Armhole Side-Bust Taper (Rows 10–11, 3.0 mm hook)

Continue the 2-row stripe sequence, maintaining the center ch-1 spine increases while switching outer row ends to double decreases so the sides pivot upward and inward along the side-bust:

  • Rows 10–11: Ch 1, [hdc2tog] x2 over the first 4 sts (-2 sts), hdc in each st to the center ch-1 space, work the listed Center Peak Action in the ch-1 space, hdc in each st until 4 sts remain, [hdc2tog] x2 over the last 4 sts (-2 sts). Turn.
  • At the end of Row 11 (C3 (Cream)), the center spine peak reaches 20.7 cm (`~21.0 cm target, 57 sts per wing). Position yarn at the outer armhole edge for the first shoulder’s short rows.

Phase 4 — Short-Row Blunted Neckline & Ochre Framing Row (Rows 12–16 + Trim)

Work each shoulder separately across 5 short rows to level off a crisp 9.0 cm horizontal collarbone edge:

  1. First Shoulder (Rows 12–16):
    • Odd Short Rows (Rows 12, 14, 16 — worked Outer Armhole \(\to\) Neck): Ch 1, [hdc2tog] x2 over first 4 sts, hdc up the wing stopping 1 or 2 sts short of the previous row’s neck end as specified in the table. Leave remaining neck st(s) unworked. Turn.
    • Even Short Rows (Rows 13, 15 — worked Neck \(\to\) Outer Armhole): Do not ch 1; sl st loosely across the first 1 or 2 neck sts as listed in the table, ch 1, hdc in next st and down the wing until 4 sts remain, [hdc2tog] x2 over last 4 sts. Change color at the outer armhole edge after every 2-row stripe. Fasten off after Row 16 (C1 (Forest Green), 40 live diagonal armhole sts remaining).
  2. Second Shoulder (Rows 12–16): Join C3 (Cream) at the opposite outer armhole edge and mirror Rows 12–16 identically. Fasten off.
  3. Collar & Armhole Framing Row (Row 17, C2 Ochre, 3.0 mm hook): With RS facing, join C2 (Ochre) at the right bottom underarm marker. Ch 1, work 58 sc evenly up the right side-bust row ends and across the 40 live diagonal shoulder stitches to the right collarbone corner (2 sc in corner), work 19 sc evenly across the stepped short-row ends + center ch-1 peak to form a smooth 9.0 cm horizontal collar (2 sc in left collarbone corner), and work 58 sc down the left live diagonal shoulder stitches and left side-bust row ends to the left underarm marker. Fasten off C2.
